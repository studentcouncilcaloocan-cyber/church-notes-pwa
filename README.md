MCGI Notes v1.4.3 — Smart Auto-Formatting

Based on v1.4.2. Adds smart-format.js for quote blocks and automatic lists. No IndexedDB schema or backup changes.

Type a double quote at the beginning of an empty paragraph to start a quote block; type a closing double quote at the end to leave it. Type - followed by space or 1. followed by space at the beginning of a paragraph to create lists. Native browser list Enter/Enter-again behavior applies.

Verification: JavaScript syntax and ZIP integrity checks only. Actual desktop/mobile browser interactions are NOT yet verified. Back up notes before deployment.
