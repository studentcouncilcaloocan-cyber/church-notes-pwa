# MCGI Notes v1.5.6 — Mobile UI refinement

Mobile-only UI changes: compact sidebar, Settings source-label layout, Bible chapter/verse picker with automatic reading/search, Notes Editor highlight palette, Verse of the Day preview/actions, and scrollable Bible verse results. Existing notes, Bible IndexedDB, and other application functions are retained in source.

Important: This distribution intentionally does not include `videos.json` or `.github/workflows` so uploading its contents to the existing GitHub repository does not overwrite the already populated 311-video catalog or the catalog automation workflow. Keep those existing repository files. Upload the included files to the repository root; do not delete existing files. The current site remains unchanged until you commit.

Static JavaScript syntax and ZIP integrity checked. Real browser/PWA behavior, offline library integration, and autoplay have not been verified. Back up notes before deployment.
